## 🧠 What Interests Me

### Systems

There is something fascinating about seeing what happens underneath an application — processes running in the background, services communicating with each other, logs telling a story, and resources being consumed in real time.

### Cloud

Cloud platforms make infrastructure more dynamic, flexible, and interconnected. I enjoy understanding the relationship between compute, networking, identity, storage, databases, and the services built on top of them.

### Networking

Networking is one of those areas where a small detail can explain a much bigger problem. IP addresses, DNS, ports, routes, protocols, and connectivity all tell a story about how systems communicate.

### Linux

The command line provides a direct window into a system. Working with Linux makes it possible to understand and interact with infrastructure at a much deeper level.

### Containers

Containers bring another interesting layer between applications and infrastructure. Understanding how images, processes, networking, configuration, and resources interact makes containerized environments much easier to reason about.

### Automation

I enjoy using simple tools and scripts to make repetitive technical work easier, faster, and more consistent.
